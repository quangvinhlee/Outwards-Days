# Prototype privacy notes

Outwards Days stores availability, interests, duration/effort limits, approximate area, plans, optional completion feedback and written mini-mission notes. Notes are saved locally as drafts and sent with a completion event. Up to two short note excerpts and one feedback excerpt per recent completed outing can be sent to the configured Gemma service during future plan generation, to choose a reflection style; the server also uses notes and feedback to create follow-up prompts. Avoid writing sensitive details you do not want in your activity history or inference context. If Gemma is configured remotely, that endpoint's operator can process the excerpts. The app does not need employer names, an exact home address or continuous location. Foreground location is optional and coordinates are rounded to two decimal places before sending them. Camera access is optional and requested only when a user starts a photo mission.

The API processes schedules and preferences. MongoDB hosts cloud data when configured; a local file is used only for development. The self-hosted model receives eligible slots and preferences rather than raw commitments. Open-Meteo and the configured OpenStreetMap/Overpass place provider receive coarse coordinates when location is enabled. SerpApi receives area search terms and coarse coordinates when enabled. Self-hosting inference does not make the app entirely on-device.

A random 256-bit guest token is stored in the phone's SecureStore; only its SHA-256 hash and expiry are stored on the server. Expiry is checked on every request. This prototype has no cross-device account recovery. Keep that limitation visible before distributing publicly.

Saved plans, drafts and queued completion events live in SQLite on the device. Optional local reminders contain activity titles. “Delete my data” removes the owner aggregate, sessions, local cache, outbox and reminders after an authenticated server deletion. It requires connectivity. Host backups may follow separate infrastructure retention policies.

For a photo mission, the app resizes the captured image and sends it to the API, which re-encodes it as a small JPEG without EXIF metadata before forwarding it to the configured Gemma vision service. The API stores only the selected subject and verification time, not the image. A self-hosted inference endpoint should be used for private photos; operators of a remotely configured endpoint can process those photos. Verification checks visible content only and cannot prove where or when a photo was taken. Do not photograph children, strangers or dogs without the owner's consent.

API errors expose request IDs. Logs omit bearer tokens, raw schedules, photos and model prompts/responses. Provider caches are bounded and expire; timestamps remain attached to saved forecasts. This document describes the prototype, not a final app-store privacy policy.
