# Outwards-Days

A native outdoor planner for the time you actually have. Confirm your week, review small outdoor moments, accept one, and record how it went—even offline.

Built with Expo / React Native, Fastify, Luxon, Zod, a Mastra workflow, and Gemma through Ollama. The scheduler owns availability and time budgets. The model chooses and personalizes activities; it cannot override constraints.

## Run locally

Requires Node 24, pnpm 10.32.1, Docker Compose, and Ollama for live AI.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm setup:local
ollama pull gemma4:e2b
pnpm dev:api
```

In another terminal:

```sh
# Uses apps/mobile/.env, generated by setup.
pnpm dev:mobile
```

Use Expo Go matching SDK 57, or build Android with `pnpm --filter @outsideweek/mobile android`. On iOS use a Mac/Xcode or an appropriately provisioned EAS build. See [setup](docs/setup.md).

Setup generates private environment files and separate random MongoDB admin/app passwords, starts authenticated MongoDB on loopback port 27019, and preserves data in a Docker volume. The API runs on port 3100; Metro uses 8083. Existing non-empty environment values are preserved. Production requires MongoDB and authenticated HTTPS inference. The app never holds provider credentials. Without Ollama the workflow produces explicitly labelled basic catalogue suggestions, not simulated AI.

## Working flow

- Native Today, Week and You tabs; interests, effort, travel estimates and equipment preferences.
- Seven-day schedule with multiple busy blocks, overnight commitments, explicit lunch gaps, preferred outdoor windows and weekly confirmation.
- Deterministic availability, DST review, full time budgets, frequency limits and acceptance validation.
- Persistent generation jobs, bounded model repair, visible fallback, optimistic revisions and owner-scoped guest auth.
- Accept, replace, move, skip, complete, partly complete, feedback and weekly history.
- SQLite cache and persistent completion outbox; guest token/expiry in SecureStore.
- Optional location and local reminders. Open-Meteo conditions/daylight; a nearby-place browser and sourced park/loop-hike suggestions when location is supplied; optional SerpApi park results.

## Verify

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm --filter @outsideweek/mobile exec expo install --check
pnpm --filter @outsideweek/mobile exec expo export --platform android --platform ios
pnpm check:local
pnpm test:smoke
pnpm eval:live
```

The live evaluation requires Ollama. It records actual source, validation result, timing and model digest; a basic fallback is never counted as live-model success.

## Scope and status

This implements the plan's first playable product slice. Read [implementation status](docs/implementation-status.md) for verification evidence and remaining work. A sourced loop hike can be scheduled only when mapped distance, travel allowance, full time budget, daylight, weather and effort all fit. Otherwise it remains an idea. Mapped coverage is incomplete; straight-line distance is not travel time. See [place discovery](docs/places.md). Real-phone and real-outdoor demonstration require a person and remain explicit checklist items. Paid deployment and challenge submission have not been performed. Internal `@outsideweek/*` package names, the database name and the Android application ID remain stable so existing installations and local data continue to work.
